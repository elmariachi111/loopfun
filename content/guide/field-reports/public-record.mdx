<Accordion title="The original Ralph loop (Geoffrey Huntley, 2025)">
- **Loop:** goal loop (Layer 2), shell `while` around a headless agent.
- **Goal:** whatever `PROMPT.md` says, usually "work through the spec, update progress, commit".
- **Worked:** fresh context each pass; the workspace as memory; absurd persistence.
- **Hurt:** no exit condition, credit burn, inconsistent results, and only works with self-verification.
- **Sources:** [Steve Kinney](https://stevekinney.com/writing/the-ralph-loop), [Kingy AI](https://kingy.ai/news/what-is-a-ralph-loop-how-a-bash-one-liner-became-an-ai-coding-pattern/), [Sid Bharath](https://sidbharath.com/blog/ralph-wiggum-claude-code/)
</Accordion>

<Accordion title="Long-running harness: initializer + coding agent (Anthropic, Nov 2025)">
- **Loop:** multi-session goal loop with structured handoffs.
- **Goal:** build an app from a feature list; mark features done only after testing.
- **Worked:** progress file, feature list and git as cross-session state; one increment per session.
- **Hurt:** agents declaring the project finished too early; context compaction alone was not enough.
- **Source:** [Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents) <Evidence level="primary" />
</Accordion>

<Accordion title="Planner → generator → evaluator (Anthropic, Mar 2026)">
- **Loop:** meta-loop (Layer 4) of three specialised agents over multi-hour runs.
- **Goal:** sprint contracts negotiated between generator and evaluator before each feature.
- **Worked:** rich full-stack apps; an evaluator that tests the running app via Playwright.
- **Hurt:** cost (about 6 h and $200, roughly 22× solo, per a secondary source <Evidence level="secondary" />); the evaluator was later cut back as the model improved.
- **Sources:** [Anthropic](https://www.anthropic.com/research/harness-design-long-running-apps) <Evidence level="primary" />, [Ruh AI](https://www.ruh.ai/blogs/anthropic-3-agent-harness-design)
</Accordion>

<Accordion title="autoresearch (Andrej Karpathy, Mar 2026)">
- **Loop:** metric loop: edit `train.py`, run exactly 5 minutes, read the metric, keep or revert.
- **Numbers:** about 700 experiments in two days; 11% training speedup when applied to a larger model.
- **Worked:** a deterministic judge (the metric) and a fixed budget per experiment.
- **Hurt:** only applies where results can be scored objectively.
- **Sources:** [Fortune](https://fortune.com/2026/03/17/andrej-karpathy-loop-autonomous-ai-agents-future/), [Noqta](https://noqta.tn/en/news/karpathy-autoresearch-autonomous-ai-research-open-source-2026) <Evidence level="secondary" />
</Accordion>

<Accordion title="173 continuations in 48 minutes (Codex goal mode, 2026)">
- **Loop:** Codex `/goal` waiting on an external process.
- **Hurt:** re-fired about 0.03 s after each turn; each continuation re-read 120k–470k tokens until a 429. Across 3,808 sessions, the 52 goal sessions used about half of all input tokens.
- **Lesson:** goal loops need a way to *wait*.
- **Source:** [relux.works](https://relux.works/en/blog/codex-goal-token-burn/) <Evidence level="anecdotal" />
</Accordion>

<Accordion title="The $47,000 ping-pong (multi-agent, 2026)">
- **Loop:** four LangChain agents, two of which kept sending requests to each other.
- **Numbers:** 264 hours; about $47,000; stopped only when someone saw the billing dashboard.
- **Lesson:** loops between agents need budgets and livelock detection just as much as single-agent loops.
- **Source:** [AI agent API cost horror stories](https://baeseokjae.github.io/posts/ai-agent-api-cost-horror-story-2026/) <Evidence level="anecdotal" />
</Accordion>
