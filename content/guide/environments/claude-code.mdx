Claude Code is where many loop patterns were first tried, partly because its team uses it this way. Boris Cherny, who leads Claude Code, reportedly said in June 2026: "I don't prompt Claude anymore. I have loops prompting Claude and figuring what to do" ([The New Stack](https://thenewstack.io/loop-engineering/), [Paweł Huryn on X](https://x.com/PawelHuryn/status/2069363303952818474)). <Evidence level="secondary" />

## How the goal loop behaves

<Cycle steps={['Claude works', 'Tries to stop', 'Evaluator checks', 'Not met: continue']} highlight={2} center="/goal" />

The evaluator is the interesting design choice. Because it's a **different, smaller model**, it's cheap to run every turn and doesn't share the worker's optimism about its own work. But it reads the **transcript**, not the world, so it judges what the agent *reported*. That makes [checkable goals](/guide/goals/writing-goals) that point at concrete commands (whose output appears in the transcript) much more reliable than vague ones.

Guides consistently warn about two failure modes: goals the evaluator can't check (so the loop can't stop), and impossible goals (Claude can loop indefinitely) ([XDA](https://www.xda-developers.com/finally-understood-claude-code-goal-command/), [MindStudio](https://www.mindstudio.ai/blog/claude-code-goal-command-autonomous-agents)).

## Which primitive for which job?

| You want… | Use |
|---|---|
| "Keep going until the tests pass" | `/goal` |
| "Check this every 10 minutes" | `/loop` |
| "Every weekday at 9" | Routines / scheduled tasks |
| "Run this in the background while I do other things" | `--bg` plus Agent View |
| "Several agents on one big project" | Agent teams, worktrees |
| "Custom logic for whether to stop" | A Stop hook |

[MindStudio's comparison](https://www.mindstudio.ai/blog/claude-code-goal-routines-loop-autonomous-scheduling) goes deeper on `/goal` vs. routines vs. `/loop`.

## Limits and pricing

Loops are what pushed Anthropic to add **weekly limits** in 2025, aimed at continuous 24/7 use ([TechCrunch](https://techcrunch.com/2025/07/28/anthropic-unveils-new-rate-limits-to-curb-claude-code-power-users/)). Heavy loop users have reported exhausting weekly limits in one or two days ([issue #9424](https://github.com/anthropics/claude-code/issues/9424), [#76006](https://github.com/anthropics/claude-code/issues/76006), [The Register](https://www.theregister.com/2026/01/05/claude_devs_usage_limits/)). In late October 2026 Max 20x was renamed **Ultra**, and the five-hour limit was removed for verified Ultra accounts; weekly limits remain. Sources disagree on whether that covers interactive Claude Code sessions ([Developer's Digest](https://www.developersdigest.tech/blog/claude-ultra-plan-max-20x-rename-five-hour-limit-2026), [Requesty](https://www.requesty.ai/blog/claude-max-plans-5-hour-limit-removed)). <Evidence level="contested" />
