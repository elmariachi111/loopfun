# Contributing to loop.fun

We collect stories from people running agentic loops so we can learn from each other. A few ground rules keep that useful and safe.

## Ground rules

1. **Failures are welcome.** A loop that didn't work, and why, teaches as much as a success story.
2. **No secrets.** Leave out API keys, tokens, internal hostnames, customer data and proprietary code.
3. **Tell your own story.** Don't share other people's details or private conversations without their OK. If you're summarizing someone else's public write-up, link to it.
4. **Disclose interests.** If you work for, sell or invest in a tool you write about, say so.
5. **Be specific.** "The judge accepted a summary saying tests passed when they hadn't run" beats "verification was flaky". Rough numbers are fine; say they're rough.
6. **Link your sources** for any claim that isn't your own experience.

## Ways to contribute

- **Share a field report:** use the "Share your story" button on [loop.fun/guide/field-reports](https://loop.fun/guide/field-reports). It opens GitHub with a short template, and reports land in `content/guide/field-reports/`.
- **Fix or extend a page:** use "Improve this page" at the bottom of any page.
- **Argue with something:** use "Disagree? Discuss" to open an issue.
